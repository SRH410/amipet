# JavaScript de AmiPet

Esta carpeta contiene la funcionalidad del Sprint 2.

## Estructura

- `main.js`: inicializacion de los modulos segun la pagina.
- `modulos/validaciones.js`: validacion de formularios.
- `modulos/almacenamiento.js`: uso de localStorage para datos no sensibles.
- `modulos/autenticacion.js`: interacciones de inicio de sesion y registro.
- `modulos/mascotas.js`: consulta y filtros de mascotas.
- `modulos/postulaciones.js`: registro y consulta de postulaciones.
- `modulos/chatbot.js`: interfaz del agente AmiPet.
- `servicios/api.js`: comunicacion con la API REST.

## Criterios

- Mantener el JavaScript separado del HTML y CSS.
- Usar modulos ES y eventos con `addEventListener`.
- No agregar claves privadas ni tokens al codigo del navegador.
- No simular conexiones reales: cada integracion se documentara cuando exista un servicio disponible.
- Mantener la identacion y los nombres en espanol, siguiendo la estructura actual del proyecto.
